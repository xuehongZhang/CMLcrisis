Paired Longitudinal Single-Cell Profiling Reveals Clonal Evolution and Lymphoid Lineage Restriction During Progression from Chronic-Phase CML to B-Lymphoblastic Blast Crisis

Data availability:
The publicly available scRNA-seq data used in this study are available in the Gene Expression Omnibus (GEO) under accession no. GSE130116 for two patients with de novo Ph+ B-ALL, 
and GSE76312 for patients with CML-CP and CML-BLBC. The publicly available microarray data used in this study are available under accession no. GSE47927 for patients with CML-CP and CML-BP, 
and GSE14671 for imatinib responders and nonresponders collected from treatment-naïve patients with CML-CP. Newly generated human scRNA-seq data and bulk RNA-seq were submitted to the GEO repository 
and can be accessed under GEO accession no. GSE333588 and GSE337046, respectively.

Code availability
The code to reproduce the key findings is available on GitHub at https://github.com/xuehongZhang/CMLcrisis.
